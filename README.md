# StagePlaatser v0.3

Proof of concept voor de stageplaatsing binnen dNP.

## Rondevolgorde

1. J4
2. Langstudeerders
3. Profileringen
4. J2
5. J1

Er is bewust geen reguliere J3-ronde.

## Bereikbaarheid

Een plaatsing geldt als normaal bereikbaar wanneer:

- OV maximaal 60 minuten duurt, of
- fietsen maximaal 30 minuten duurt.

Andere combinaties worden niet direct uitgesloten, maar komen in Human Review.
